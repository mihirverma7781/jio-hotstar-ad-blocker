# Design System: HyperSkip

<!-- impeccable:design-schema 1 -->

## World: Minimalist Monochromatic Titanium

A Swiss-engineered, brutalist-clarity design system for high-velocity playback automation. Zero gradient-mesh decoration, zero floating pastel blobs, zero AI slop clichés. High contrast, precise hairline borders, structural micro-grids, and monospaced telemetry.

### Palette

- Background Canvas: `#090A0C` (Carbon Black)
- Surface Deep: `#101216` (Titanium Charcoal)
- Surface Elevated: `#181B20` (Machined Slate)
- Border Hairline: `rgba(255, 255, 255, 0.09)`
- Border Accent / Active: `rgba(255, 255, 255, 0.22)`
- Text High-Contrast: `#FFFFFF`
- Text Secondary: `#9EACB9`
- Text Tertiary: `#606973`
- Functional Indicator (Active / Engaged): `#22C55E` (Emerald Laser)
- Functional Warn / Ad Trigger: `#F59E0B` (Amber Warning)

### Typography

- Body & Headlines: Inter / Plus Jakarta Sans / system sans (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`), tracking `-0.025em`, crisp weights (500, 600, 700). No gradient fills on text.
- Telemetry & Measurements: `ui-monospace, "JetBrains Mono", SFMono-Regular, Menlo, monospace` with tabular numerals (`font-variant-numeric: tabular-nums`).

### Iconography & Graphics

- Custom sharp SVGs (1.5px stroke, crisp geometric vectors).
- Official Brand Logo: Precision dual chevron with an acceleration telemetry block.
- Zero emojis used as UI icons (replaced with precise SVG glyphs).

### Interaction Physics

- Crisp 120ms - 150ms cubic-bezier(0.16, 1, 0.3, 1) transitions.
- Tactile inset border states on button presses.
- Focus rings: 2px solid `#FFFFFF` with 2px offset.
