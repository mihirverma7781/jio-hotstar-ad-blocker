## World: Engineered Precision Titanium

Minimalist, high-craft streaming utility design system with Space Grotesk display typography, JetBrains Mono telemetry, Electric Sapphire primary action accents, and Laser Emerald semantic indicators.

### Tokens

- Canvas: `#080c14`
- Elevated Card: `rgba(15, 23, 42, 0.75)`
- Border Hairline: `rgba(255, 255, 255, 0.08)`
- Primary Accent: `#2563eb` (Electric Sapphire)
- Telemetry Accent: `#38bdf8` (Precision Sky)
- Semantic Success: `#10b981` (Laser Emerald)
- Semantic Warning: `#f59e0b` (Ad Break Amber)

### Typography

- Display / Headings: `Space Grotesk`
- Body: `Inter` / system sans
- Telemetry / Numeric: `JetBrains Mono` with `tabular-nums`
